# Students Database CRUD API (FastAPI + SQLite)

A REST API for managing student records with full Create, Read, Update, and Delete (CRUD) operations. Built with Python, FastAPI, SQLAlchemy, and SQLite.

## Features
- Create, Read, Update, and Delete student records
- Persistent storage using SQLite
- Data validation with Pydantic
- Swagger UI for interactive API testing

## Tech Stack
- Python 3.14
- FastAPI
- SQLAlchemy (ORM)
- SQLite
- Uvicorn
